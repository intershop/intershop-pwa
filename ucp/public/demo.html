Intershop UCP - Agentic Commerce Playground

A live, step-by-step walkthrough of how a shopping agent (Google AI Mode, Gemini, …) discovers an Intershop store's catalog through the Universal Commerce Protocol (UCP). Each step shows the exact request the agent sends, the response the UCP service returns, and what happens against ICM behind the scenes. Scope is deliberately non-transactional: Search and Lookup only.

1
Discovery The agent reads the business profile at /.well-known/ucp
Before doing anything, an agent discovers what a business supports. It fetches the public UCP profile - no authentication required - to learn which capabilities the store offers, the spec versions and transport, and where the catalog endpoint lives. This business declares the non-transactional catalog.search and catalog.lookup capabilities only.
2
Product discovery The agent searches the live catalog and picks an item
The agent searches the store's live ICM catalog via the standard UCP Catalog capability (dev.ucp.shopping.catalog.search → POST /catalog/search, advertised in the profile). The service maps each ICM product to a UCP product with one or more variants. Click one or more products to select them and look them up together in the next step.
then click one or more product cards ↓
3
Product lookup UCP catalog.lookup → resolve full detail by identifier
The agent resolves the selected product(s) to their full UCP representation with a single POST /catalog/lookup (dev.ucp.shopping.catalog.lookup). One batch call takes all selected ids and returns one products array - each variant's inputs correlates a result back to the id that requested it. Unknown ids come back as messages (HTTP 200), not errors.
